# PremiumREA Suburb Stats

Open [Suburb Stats](https://premiumrea.com.au/tools/suburb-stats) and find the public brief for the exact suburb/state/postcode in the suburb index. Where available, follow the indexed /tools/suburb-stats/<suburb-postcode> link. Confirm the page title and geography, especially for suburbs with a shared name or postcode. The brief is ordinarily readable by web tools without a browser session. With Agent Reach available, use its normal web reader or switch to available web search or browser tools if needed.

From a published brief capture relevant facts, such as house/unit sale medians, matched rental bond medians and counts, estimated resident population, new dwelling approvals, recorded offences and school context. Record the direct URL, access date, each figure's original publisher, reporting period and geographic boundary, and the bedroom/dwelling category and count when applicable. The web page update date is separate from the statistics' reference periods. Clearly label SA1, SA2, combined rental region, postcode, LGA and suburb figures. An aggregate used as a benchmark should have a relevant comparison and should not be used as property-specific evidence.

Use the interactive map's exact address pin when lot context is relevant and the map is available. Check the matched address and parcel, then collect only decision-relevant visible map fields after the layers finish loading. Use the appropriate official parcel/planning report, title and plan, flood authority and government school catchment for confirmation. Keep a material mismatch visible, with the layer and boundary tested, until authoritative evidence resolves it. The map's easement feature count, cadastral line records and legal title entries are different measurements. School locations do not identify the property's catchments.

Use the public interface for the individual property or suburb being assessed. A signed-in report request is a separate PremiumREA service. For a local PDF, read the available sources and build the report in the skill without submitting that request. If a brief or map is unavailable, continue with the original government publications and the available listing/rent evidence. In Victoria the usual fallbacks are Homes Victoria, Valuer-General Victoria, ABS, Crime Statistics Agency, VicPlan, the local council and Find My School. Record any unresolved field and keep the 4%, 5% and 6% property model based on matching local evidence or a labelled scenario.
